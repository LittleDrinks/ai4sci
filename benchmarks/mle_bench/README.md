# MLE-bench Kaggle engineering
Official commit `507f92e1138bb6e40dac5c6ee7a6758e6424bf97` (2026-04-24, tip of main) is cloned at `source/`, MIT. `python -m compileall mlebench experiments` passes; all 322 Git-LFS objects (leaderboards, checksums, published grading reports) are pulled and verified readable. Package requires Python ≥3.11 and heavy deps (tensorflow, docker, kaggle 1.6.x); it is not installed locally.
## Prepare chain and the Kaggle block (需人工操作 Kaggle 账号)
`mlebench prepare --lite` calls the Kaggle API `competition_download_files` per competition (`mlebench/data.py`); an account that has not accepted a competition's rules gets HTTP 403 "You must accept this competition", and the CLI then prompts to open `https://www.kaggle.com/c/{competition-id}/rules`. MEMORY.md records exactly this state: the chain itself was ready, and `nomad2018-predict-transparent-conductors` returned 403. That record predates this collection and was not re-run (no Kaggle credentials here), so the 403 status is assumed unchanged. Unlock steps:
1. Register/verify a Kaggle account (some competitions require phone verification) and place `kaggle.json` in `~/.kaggle/`.
2. For each of the 22 Lite competitions below, open `https://www.kaggle.com/c/<id>/rules` and click Accept — the rules are per-competition, so all 22 must be accepted individually.
3. Re-run `mlebench prepare --lite` (or `-c <id>` per competition). Downloads then succeed and are checksum-verified against the pinned `checksums.yaml`.
