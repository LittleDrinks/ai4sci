# SearchBench
`runner.py` 比较同一 Matbench `matbench_expt_gap` 题面下的四种规划策略：独立盲创、盲创被拒后新会话反思、盲创被拒后原会话反馈、直接反思。一次盲创同时供前三个策略使用；只有两个入图审核者一致拒绝才触发后续分叉，分歧停在人工审核，不人为制造失败。
反思只看到一条来自 Matbench 官方提交的已入图路线；盲创只看到任务契约。规划输出不含方法族自标签。首轮只检验候选与入图审核，候选执行继续使用 Matbench 官方五折、记录、验证和评分接口。
## 首轮结果
远端产物位于 `/data/zsm/ai4sci-design-bench-20260809/search-v2/full-run1`：9 个共享 case 触发 20 次规划调用和 457373 Token，15 个候选通过双维度审核、4 个待人工、1 个格式拒绝；只有 1 个真实拒绝，产生 2 条转移分支，尚不足以比较两种失败后策略。
15 个通过候选在 `/data/zsm/ai4sci-design-bench-20260809/search-v2/family-run1` 抽取 30 对，两个独立审核者共完成 60 个会话：22 对同机制、4 对异机制、4 对分歧；15 个闭合三角形出现 3 个传递性冲突。成对结果只能作为带来源的局部关系，不能用并查集自动闭包成方法族。
blind 与 reflect 都集中到元素 token、attention 和图消息传递。当前证据更像模型先验或题面诱导导致的搜索空间坍缩，不能证明历史上下文造成锁死，也不能证明 blind 更创新。
## 模型对照
`gpt-5.6-luna` 在相同题面完成 3 个 case、6 次规划和 159240 Token：3 个候选通过、3 个待人工，没有真实拒绝或策略转移。候选主要采用核相似度插值、显式元素对交互和鲁棒线性模型，与 Mini 的图消息传递集中明显不同。
每个模型按候选内容哈希确定性抽取 3 个通过候选，在 `/data/zsm/ai4sci-design-bench-20260809/search-v2/cross-model-family-run1` 完整审核 15 对。9 个跨模型对为 8 个明确不同、1 个审核分歧；Mini 内部 3 对为 2 同、1 分歧；Luna 内部 3 对为 2 异、1 同。双审核共 30 个会话、168324 Token，无解析错误或传递冲突。单模型先验会显著限制可见搜索空间；规划调度需要把模型差异作为独立变量，不能只比较同一模型的上下文策略。
## 多路线审核
v3 把历史从单条 RF-Magpie 扩为 RF-Magpie 与 CrabNet 两条已入图路线。候选分别与每条路线接受两个独立审核；任一路线被一致判同即拒绝，全部路线均被一致判异才接受，其余进入人工审核。`/data/zsm/ai4sci-design-bench-20260809/search-v3/multi-route-run1` 的 3 个 case 共调用 6 次规划、消耗 200657 Token，5 个候选通过、1 个待人工，仍无真实拒绝。候选的 DeepSets、图消息传递和双线性交互均被判断不同于 CrabNet 自注意力。结果验证了多路线门禁的运行方式，但没有产生足以比较失败后策略的自然事件；方法粒度与历史覆盖仍是待测变量。
## 拒绝恢复控制
恢复控制先生成一个候选，再把它作为已确认重合的历史路线；同一任务比较重新盲创、全新反思、原会话接收最小驳回三种恢复。它只测已知拒绝后的逃离能力，不估计自然拒绝率。
`gpt-5.4-mini` 的三个 case 中，重新盲创、全新反思、原会话反馈分别有 0/3、0/3、1/3 被双审核判为不同机制；其余都回到元素图消息传递。唯一通过者把显式图消息传递改成带 pairwise bias 的 token self-attention，机制边界仍可人工质疑。执行维度共 7 个通过、1 个待人工、1 个拒绝；校正初始控制调用后共 240746 Token。
`gpt-5.6-luna` 在相同控制中三种恢复均为 3/3 不同机制，候选转向核、邻域插值和 gated contribution；但执行维度只有 2 个一致通过，其余 7 个分歧或不确定，共 272930 Token。两模型差异远大于同模型内三种恢复策略差异。模型选择应作为搜索策略变量，机制广度与执行有效性必须分别报告；当前每格仅 3 个 case，不能排序恢复策略。
