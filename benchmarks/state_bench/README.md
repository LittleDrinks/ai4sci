# STATE-Bench experience disclosure
Official commit `5644b1838d96bc4483da29642d058ecaa6f80f7f`, MIT, is extracted remotely at `/data/zsm/ai4sci-design-bench-20260809/state-bench/source`; archive SHA-256 `746646f24ab0ebd713ae28f0e96c1cc81cdbe9598171a2f7ed37953ce7a0b96a`. The Agent Learning Track supplies 100 train trajectories and 50 held-out tasks in each of travel, customer support and shopping, a read-only `retrieve_learnings(query, top_k=3)` hook, stateful tools, deterministic assertions, fixed simulator and judge, five-run completion reliability and cost metrics.
Compare four artifacts with the same Qwen agent and official protocol: empty retrieval; unfiltered trajectory learnings; graph-scoped admitted learnings; admitted learnings plus rejected records visible only to a retrieval auditor. Every group registers the same tool and `top_k=3`; the empty group returns `[]`. Pair results by held-out task and report pass@1, pass^5, invalid state mutations, turns, retrieval calls, disclosed tokens, build cost and run cost. Count tasks harmed by unfiltered history and recovered by audited retrieval without inventing a failure taxonomy. This benchmark decides experience-disclosure policy; its enterprise tasks do not define scientific graph schema or mechanism novelty.
The package requires Python 3.12 while the remote system Python is 3.10. A checksum-verified uv 0.12.3 installed an isolated CPython 3.12.13 environment from the official lock; upstream tests pass `148 passed, 1 skipped`. Its built-in agent uses Responses; Qwen on Bailian should use the official custom `BaseLLMClient` and `BaseAgent` extension points to translate OpenAI-style tools to Chat Completions. Keep the official orchestrator, domain tools, retrieval hook and scorer unchanged. An official run still requires the protocol-locked GPT-5.4 simulator and judge credentials.
The 300 train files contain only canonical conversations, not gold success labels: 2319 messages, 2842 tool calls and about 749K text characters; the longest conversation has 31 messages. Admission or isolation must therefore be produced by the system under test. Held-out task state decides whether the resulting disclosure policy helped. Use AMA-Bench and real research runs for longer-scale stress.
