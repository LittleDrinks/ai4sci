# 参赛资格

- 研0：入读学校和本科院校不同则无参赛资格；以本科院校身份参赛（应届毕业生）可以。未入学的研0 不能以研究生学校名义参赛。
- 2026-06-01 前注册的全日制非成人教育在校专科/本科/硕士/博士（不含在职）可报；年龄 <40（1986-06-01 后出生）。
- 指导老师须是高校老师（外校也可以）；可以无指导老师（让学院老师签字，签时写在校职务+身份证号）。
- 一个老师不建议指导 >2 支队伍（无硬性规定）。

# 组队

- 跨校可以，但只从一所申报主体学校申报；跨校盖章、证明、公示需双方配合；获奖证书只发给申报主体学校。
- 同一人可报不同赛道不同题目，但不能用同样核心技术内涵包装成不同题目。
- 本硕博可一起组队。
- 报名后成员排名不可改（盖章报名表以系统导出为准，不要自行调整）。
- 现场答辩：往年排序前两位上台，今年等擂主赛通知。

# 盖章

- 资格1：学籍部门章（教务处/学生处），优先学校学籍处，难申请可学院章；所有学校都要盖，外校先盖、申报主体最后盖。
- 无团委学校：用校级学工/双创/教务部门章替代 + 情况说明。
- 资格3（联合单位）：申报人所在校团委盖章即可；科研院所团委需查是否符合要求。
- 跨校盖章：分别打印各自盖章后汇总一份，或合并扫描件均可；不可 PS 合成章。
- 签名必须手签（资格2），只有签字可手写，其他信息不能手写添加。

# 报名

- 截止 6-30 24 点（去年口径），建议提前交，别压最后一天（系统卡顿/来不及改）。
- 流程：校团委审核 → 发榜单位审核 → 通过即报名成功。
- 提交后系统不能改的就不能改了，最终提交作品可稍作修改。
- 退回常见原因：成员排序不一致、申报种类错误（1人=个人项目，>1人=集体项目，指导老师不算）。
- 作品编号在报名表左上角。
